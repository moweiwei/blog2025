# 接口

> 类和接口的关系

![1](/docs/src/public/java笔记/image.png)

> 抽象类和接口的区别

- 抽象类：对事物做抽象（描述事物）
- 接口：对行为抽象（制定规则）

![1](/docs/src/public/java笔记/1.png)

默认方法不强制要求重写，可以重写;默认方法的 public 可以省略；default 不能省略；

```
public default void create(){}
```
